# 植物大战僵尸 - Python版

## 运行方式

### 方式一：双击启动
双击 `启动游戏.bat` 即可运行

### 方式二：命令行
```bash
cd pvz_game
python main.py
```

> 依赖：`pygame`（`pip install pygame`）

---

## 操作说明

| 操作 | 功能 |
|------|------|
| **拖拽底部植物卡片到草地** | 种下植物 |
| **拖拽铲子到植物上** | 铲除植物 |
| **左键点击阳光球** | 收集阳光 |
| **R** | 重新开始当前关卡 |
| **ESC** | 返回菜单 / 退出 |

## 游戏策略

1. **优先种向日葵**：前排种 2-3 个向日葵保证阳光收入
2. **豌豆射手当主力**：在向日葵前面布置射手输出
3. **坚果墙当肉盾**：最前排放坚果拖延时间
4. **樱桃炸弹清场**：遇到大群僵尸时使用
5. **寒冰射手控场**：减速高血量僵尸争取输出时间
6. **夜晚用阳光菇**：费用低，成熟后产量可观

## 项目结构

```
pvz_game/
├── main.py          # 游戏主文件（主循环、事件处理、游戏逻辑）
├── constants.py     # 常量配置（窗口、网格、植物/僵尸数据、关卡定义）
├── plants.py        # 植物类（10种植物）
├── zombies.py       # 僵尸类（7种僵尸）
├── projectile.py    # 子弹与特效（豌豆、阳光球、爆炸）
├── ui.py            # 界面绘制（背景、顶栏、植物选择栏、铲子）
├── menu.py          # 主菜单与关卡选择
└── 启动游戏.bat     # Windows 启动脚本
```
